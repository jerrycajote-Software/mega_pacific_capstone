# ADR-002: Use Prisma ORM v7 for Database Access

## Context
The project needs an efficient database abstraction layer in Node.js that provides type safety, schema migration management, and clean data modeling.

## Decision
We select **Prisma ORM v7** as the database mapping tool.

## Rationale
- Declarative schema definition in `schema.prisma` serves as single source of truth for the database layout.
- Auto-generated JS client provides type completion and compile-time query verification.
- Migration tooling (`prisma db push` / `prisma migrate`) simplifies database synchronization.
- Built-in seeder capability (`prisma db seed`).

## Alternatives Considered
- **TypeORM**: Flexible but more complex configuration overhead.
- **Sequelize**: Older API design with weaker type-safety guarantees.
- **Raw SQL (pg module)**: Maximum control, but requires manual boilerplate for query mapping and migrations.

## Status
**Accepted**
