# ADR-003: Use React 19 + Vite for Frontend Client

## Context
The application requires a fast, responsive user interface supporting complex interactions (variant price calculation, 3D product view, real-time messaging, dark/light theme, interactive data grids).

## Decision
We adopt **React 19** bundled with **Vite 8**.

## Rationale
- Vite provides instant HMR (Hot Module Replacement) and fast build speeds compared to legacy Webpack setups.
- Component architecture allows clean separation between layout shells (`AdminLayout`, `CustomerLayout`, `SalesLayout`) and reusable UI widgets.
- Rich ecosystem support for Material-UI, Tailwind CSS, Three.js (R3F), and Socket.IO Client.

## Alternatives Considered
- **Create React App (CRA)**: Deprecated, slower build times.
- **Next.js**: Excellent framework, but static SPA architecture with Vite fits the separate Express API deployment requirement cleanly.

## Status
**Accepted**
